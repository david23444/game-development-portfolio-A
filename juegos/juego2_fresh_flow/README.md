# 🎮 FreshFlow

## Descripción
El jugador maneja la barra de una taberna de bebidas. Van llegando clientes con
pedidos específicos (por ejemplo, "un latte con agua") y el jugador, en el rol
de bartender, debe preparar y servir la orden correcta.

**Objetivo del jugador:** atender la mayor cantidad de pedidos correctamente para
ganar dinero, sobrevivir a los eventos fortuitos (gastos/cobros que aparecen
periódicamente) y usar las ganancias para mejorar la taberna comprando más
ingredientes y ampliando el menú.
**Mecánica principal:** gestión de pedidos y recursos bajo presión de tiempo,
con progresión económica (tycoon / gestión de dinero).

## Género
Management / Tycoon

## Tecnología
HTML + CSS + JavaScript vanilla

## Controles
| Tecla / Acción | Efecto |
|---|---|
| MOUSE / CLICK | Seleccionar ingredientes y armar el pedido |
| CLICK | Servir pedido / confirmar compra de mejoras |
| ESC | Pausa |
