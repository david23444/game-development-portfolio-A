# 🎮 ¡Ahórralo, Rubén!

## Descripción
Rubén tiene que avanzar por un nivel plataformero evitando el desperdicio de agua
en el camino. El juego busca generar conciencia sobre el uso responsable del
recurso hídrico a través de una mecánica de plataformas clásica.

**Objetivo del jugador:** llegar al final del nivel sin agotar las vidas disponibles.
**Mecánica principal:** correr, saltar y esquivar obstáculos mientras se recolectan o evitan
elementos relacionados con el desperdicio de agua.

## Género
Platformer

## Tecnología
HTML5 Canvas + JavaScript vanilla

## Controles
| Tecla / Acción | Efecto |
|---|---|
